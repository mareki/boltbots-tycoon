# Product Input

> Artifact class: Navigation
> Linked owners: `AH-SPEC-DISTRIBUTION-001`, `AH-SPEC-INITIALIZATION-001`, and human-provided files named below

Human-owned, Agent-read-only source material belongs here:

- `prd.md` — required;
- `technical-requirements.md` — optional product-specific requirements/exceptions;
- `mockups/` — optional images or HTML/CSS/JavaScript source;
- `research/` and `brand/` — optional.

Before copying or executing any content, initialization classifies secrets, personal/confidential data, and usage rights. Never place secrets here. Use redacted/synthetic samples or an authorized protected-store reference for sensitive/restricted input.

These files are intent inputs, not automatically approved Product truth. After rights/safety
classification, supplied visuals are provisionally binding for their covered surfaces unless the
Human Product Authority explicitly marks a named aspect illustrative. For an existing Product,
established shared shell, Design System, global tokens, shared components and cross-page behavior
remain binding unless an exact global-change outcome authorizes their revision. General improvement
authority and silence never authorize redesign, substitution, omission or semantic reinterpretation.

Agents MUST NOT overwrite, normalize, rename, or improve these files in place. Redacted working copies, normalized requirement registers, Agent-authored draft PRDs, and proposed changes belong under `docs/product/`; only a human may supply or explicitly accept a replacement input.
