## Change And Product Impact

This patch makes existing material-UI design, screenshot and independent-review obligations
fail closed at ordinary Run admission and verification. New Runs select material, minor or
non-visual applicability. Material candidates retain only representative digest-bound raster
evidence; reviewers identify the exact images inspected. Existing mockups are compared, while an
explicit standalone path handles material UI without a mockup.

The validator checks structure, candidate/authority identity, real local image bytes and digests.
It does not judge aesthetics. Agentic Product/UX review remains responsible for composition,
hierarchy, clipping, consistency and usability.

## Recalibration

Compatible upgrade replaces only `.agentic-harness/**`; Product-owned Runs and history are not
rewritten. Existing Runs pinned below `1.0.13` retain their prior contract. New material UI Runs
must retain a small representative image set in their existing review-evidence directory and
provide it to an independent reviewer through a browser or image tool.

No Product redesign, screenshot migration, deployment, provider or AWS action is authorized.
