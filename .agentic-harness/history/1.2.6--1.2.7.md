## Change And Product Impact

New ordinary Runs use one compact Run Contract. `--check-run` reads only that Contract and its exact
named target files. It creates no Admission Projection, Admission Report, Run State Event, document
hash, digest chain or separate Agent Activation Record. Full repository validation remains separate.

This removes ordinary-Run startup work that did not advance Product/user outcomes. The Contract
still binds outcome, scope, authority, finite team/corrections, allowed actions, completion evidence
and Agent-start clearance.

## Recalibration From 1.2.6

- Replace only `.agentic-harness/**` through the authenticated upgrade path.
- Do not migrate or rewrite existing Product Runs; their pinned historical meaning remains valid.
- Use the new compact Contract only for newly authorized `1.2.7+` ordinary Runs.
- Keep repository-wide validation in CI, upgrade, release or explicit audit workflows—not Run start.

No Product-owned plan, policy, code or existing Contract requires automatic migration.
